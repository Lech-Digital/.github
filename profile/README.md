# Lech Digital

**I make things that should exist.**

Small, independent apps, built by hand in Schiedam, the Netherlands. They are mostly things I wanted
and couldn't get. The software I care most about is the software nobody has to pay for.

| | What it does | Get it |
|---|---|---|
| **[Cleared](https://lechdigital.nl/projects/cleared/)** | A quit tracker for cigarettes, heated tobacco, vapes and pouches that works with the aeroplane mode on. | [Google Play (testing)](https://play.google.com/apps/testing/com.adziusmaster.smokefree) |
| **[PurePrep](https://lechdigital.nl/projects/pureprep/)** | Turns any recipe link into just the title, ingredients and steps. | [Google Play](https://play.google.com/store/apps/details?id=com.adziusmaster.pureprep) |
| **[CoreChoice](https://lechdigital.nl/projects/corechoice/)** | A free Big Five test, then decision advice shaped by how you actually decide. | [Google Play (testing)](https://play.google.com/apps/testing/com.adziusmaster.corechoice) |
| **[Coldstart](https://lechdigital.nl/projects/coldstart/)** | Finds B2B leads overnight and drafts the first email. | [getcoldstart.nl](https://getcoldstart.nl) |
